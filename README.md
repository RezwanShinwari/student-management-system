Student Management System

A simple Python program for managing student information.

Features

- Add students
- View all students
- Search for a student
- Edit student information
- Delete students
- Calculate grade statistics
- Save student data in a JSON file

How to Run

Run the program with:

python main.py

Data

Student information is stored in:

students.json

The program creates the file automatically if it does not exist.

Built With

- Python
- JSON
